## ✨ امکانات

- 🔍 **جست‌وجوی سریع** — جست‌وجو با عنوان فارسی یا انگلیسی، همراه امتیاز IMDb و نشان دوبله/زیرنویس
- 🗂 **مرور دسته‌بندی‌ها** — فیلم‌ها، سریال‌ها، ژانرها و لیست ۲۵۰ فیلم/سریال برتر
- ⬇ **دانلود** — دانلود چند-اتصاله با aria2c (در نبودش: curl)
- 🛡️ **دانلود کاملاً امن و بدون sudo** — اجرای کاملاً غیر ریشه‌ای، اعتبارسنجی سطح دسترسی دایرکتوری، مقابله با Path Traversal و فازبندی اتمیک دانلودها
- ▶ **پخش مستقیم** — بدون دانلود، مستقیم در mpv، VLC یا PotPlayer پخش کنید
- 🌐 **به‌روزرسانی خودکار دامنه** — وقتی دامنه‌ی سایت عوض شه، خودکار تشخیص داده و به‌روز می‌شه
- 🧩 **تک‌فایل** — فقط پایتون ۳.۸ به بالا، بدون هیچ وابستگی

## 📦 نصب

### گزینه‌ی A — فایل اجرایی آماده (بدون نیاز به پایتون)

فایل `f2m-windows-x64.exe` یا `f2m-linux-x64` را از صفحه‌ی
[**Releases**](https://github.com/lombalo/film2media-cli/releases) دانلود و اجرا کنید.

### گزینه‌ی B — اجرا از سورس

نیازمند پایتون ۳.۸ به بالا:

```bash
python f2m.py
```

پیشنهادی (اختیاری):

- **aria2c** — دانلود سریع
- **mpv** یا **VLC** — پخش مستقیم

## 🚀 استفاده

بدون آرگومان اجرا کنید تا منوی تعاملی باز شود:

```bash
f2m
```

یا از دستورات مستقیم استفاده کنید:

| دستور | توضیح |
|---|---|
| `f2m search <query>` | جست‌وجوی فیلم و سریال (منوی تعاملی به‌صورت پیش‌فرض) |
| `f2m url <post-url>` | مشاهده یا استخراج لینک‌های یک پست |
| `f2m categories` | مرور دسته‌بندی‌ها و ژانرها |
| `f2m config` | نمایش تنظیمات فعال |
| `f2m config get <key>` | دریافت مقدار یک تنظیم مشخص |
| `f2m config set <key> <val>` | ذخیره‌ی مقدار یک تنظیم |
| `f2m test` | تست اتصال و دامنه‌های جایگزین |
| `f2m version` | نمایش نسخه‌ی برنامه |
| `f2m help` | نمایش راهنمای استفاده |

داخل منوهای تعاملی می‌توانید گزینه‌ها را مثل `1`، بازه‌ای مثل `1,3,5-8` یا `all` انتخاب کنید.

### 🤖 حالت‌های اسکریپت‌نویسی و خروجی ماشین‌خوان

برنامه f2m پشتیبانی کاملی برای اسکریپت‌نویسی و پایپ‌لاین‌های یونیکس ارائه می‌دهد، همراه با تفکیک دقیق داده‌ها (`stdout`) از گزارش‌ها و پیام‌های تشخیصی (`stderr`):

**۱. خروجی JSON ماشین‌خوان (`--json`)**
خروجی داده‌ها را به‌صورت استاندارد و تمیز بدون رنگ‌های ترمینال و اسپینر به `stdout` ارسال می‌کند:
```bash
# ارسال مستقیم نتایج به jq
f2m search "Inception" --json | jq '.[0].title'

# دریافت تمام ساختار پست (نسخه‌ها، کیفیت‌ها، لینک‌های دانلود)
f2m url "https://www.myf2ms.top/movies/inception-2010/" --json | jq .

# دریافت فایل تنظیمات به‌صورت JSON
f2m config --json | jq .base_url
```

**۲. خروجی متنی ساده برای پایپ‌لاین‌ها (`--plain`)**
خروجی ساده و تمیزِ جداشده با Tab یا خط جدید بدون خطوط اضافه:
```bash
# ارسال مستقیم لینک‌های دانلود به aria2c
f2m url "https://www.myf2ms.top/movies/inception-2010/" --plain | aria2c -i -

# فیلتر نتایج جست‌وجو با awk
f2m search "Inception" --plain | awk -F'\t' '{print $2, $3, $5}'

# دریافت مقدار یک کلید برای متغیر شل
BASE_URL=$(f2m config get base_url --plain)
```

**گزینه‌های سراسری (Global Options):**
- `--json`: خروجی استاندارد JSON روی `stdout` (اجرای خودکار غیرتعاملی).
- `--plain`: خروجی متنی ساده بدون رنگ روی `stdout` (اجرای خودکار غیرتعاملی).
- `--no-color`: غیرفعال‌سازی کدهای رنگی ترمینال.
- `--config <path>`: تعیین مسیر فایل تنظیمات دلخواه.
- `-h, --help`: نمایش راهنمای دستورات.
- `-V, --version`: نمایش نسخه‌ی برنامه.

### 🔢 کدهای خروج استاندارد (Exit Codes)

اسکریپت‌ها می‌توانند کدهای خروج استاندارد POSIX را بررسی کنند:

| کد | مفهوم |
|---|---|
| `0` | موفقیت‌آمیز |
| `1` | خطای کلی زمان اجرا |
| `2` | آرگومان نامعتبر، خطای نوشتاری یا تداخل فلگ‌ها |
| `3` | خطای تنظیمات (`F2MConfigError`) |
| `4` | خطای شبکه، تایم‌اوت یا عدم پاسخ دامنه‌ها (`F2MNetworkError`) |
| `5` | خطای پارس ساختار HTML یا JSON سایت (`F2MParseError`) |
| `6` | نتیجه‌ای یافت نشد (جستجوی خالی یا صفحه 404) |
| `130` | توقف فرآیند توسط کاربر (`SIGINT` / `Ctrl+C`) |

## ⚙️ تنظیمات

تنظیمات در مسیرهای استاندارد کاربری ذخیره می‌شوند (سازگار با استاندارد XDG):
- **لینوکس / مک**: `~/.config/f2m/config.ini` (یا `$XDG_CONFIG_HOME/f2m/config.ini`)
- **ویندوز**: `%APPDATA%\f2m\config.ini`
- **حالت پرتابل**: اگر فایل `./f2m.conf` در پوشه‌ی جاری باشد، اولویت پیدا می‌کند.
- **مهاجرت نسخه‌های قبل**: اگر قبلاً از فایل `f2m.conf` کنار فایل اجرایی استفاده می‌کردید، در اولین اجرا به صورت خودکار و امن به مسیر جدید منتقل می‌شود.

**مشاهده‌ی تنظیمات:**
```bash
f2m config
```

**ویرایش یک تنظیم:**
```bash
f2m config set <key> <value>
# مثال: تغییر دامنه‌ی سایت
f2m config set base_url https://www.new-domain.tld
# مثال: تنظیم پروکسی
f2m config set proxy http://127.0.0.1:8080
```

کلیدهای پشتیبانی‌شده:

| کلید | توضیح |
|---|---|
| `base_url` | آدرس دامنه‌ی اصلی سایت |
| `mirrors` | دامنه‌های جایگزین (جداشده با کاما) |
| `proxy` | پروکسی برای دریافت و دانلود (مثل `http://127.0.0.1:8080`، خالی = غیرفعال) |
| `player` | پخش‌کننده‌ی ترجیحی: `auto` / `mpv` / `vlc` / `potplayer` |
| `download_dir` | پوشه‌ی ذخیره‌سازی دانلودها |
| `search_sort` | نحوه مرتب‌سازی جستجوی سریع |
| `user_agent` | رشته‌ی User-Agent مرورگر |

**تنظیم از طریق متغیرهای محیطی (Environment Variables):**
می‌توانید هر تنظیمی را موقتاً بدون تغییر فایل بازنویسی کنید:
`F2M_BASE_URL`، `F2M_MIRRORS`، `F2M_PROXY`، `F2M_PLAYER`، `F2M_DOWNLOAD_DIR`، `F2M_SEARCH_SORT`، `F2M_USER_AGENT`، یا آدرس فایل سفارشی با `F2M_CONFIG`.

اولویت اعمال: `متغیرهای محیطی > فایل محلی f2m.conf > تنظیمات کاربری XDG > پیش‌فرض‌ها`.

## 🌐 معماری اسکریپر و شبکه

- **اسکریپر مبتنی بر DOM**: پیاده‌سازی شده با `beautifulsoup4` و پارسر استاندارد `html.parser` برای استخراج پایدار ساختار درختی HTML که تغییرات جابه‌جایی خصوصیات (attributes) و فاصله‌ها را به خوبی تحمل می‌کند.
- **کلاینت شبکه‌ی مقاوم (HTTP Client)**:
  - **تلاش مجدد محدود (Bounded Retries)**: تلاش مجدد خودکار در خطاهای موقت شبکه (تایم‌اوت، کدهای 429، 502، 503، 504) تا ۲ بار با فاصله‌ی تصاعدی (exponential backoff).
  - **پشتیبان‌گیری خودکار دامنه‌ها (Mirror Failover)**: در صورت در دسترس نبودن دامنه‌ی اصلی، درخواست‌ها به ترتیب روی دامنه‌های جایگزین (`mirrors`) ارسال می‌شوند.
  - **ریدایرکت‌های موقت در نشست (Session-Transient)**: ریدایرکت‌های دامنه فقط در حافظه و برای همان نشست فعال نگه‌داشته می‌شوند و فایل تنظیمات روی دیسک بدون تایید کاربر دستکاری نمی‌شود.
  - **پشتیبانی از پروکسی**: سازگار با پروتکل‌های HTTP، HTTPS و SOCKS5.

## 🎨 رابط کاربری ترمینال و پشتیبانی RTL

- **رابط بصری مدرن با Rich**: طراحی تعاملی زیبا با پنل‌ها، جدول‌های گوشه‌گرد، تایپوگرافی خوانا و اسپینرهای وضعیت تمیز روی `stderr`.
- **نمایش پایدار و ایمن متون فارسی و دوجهته (BiDi)**:
  - **تفکیک ستونی ساختار**: عنوان فارسی، عنوان اصلی انگلیسی، سال انتشار و امتیاز در ستون‌های جداگانه قرار دارند تا از به‌هم‌ریختگی کلمات فارسی و انگلیسی جلوگیری شود.
  - **حفظ دقیق لینک‌ها و مسیرها (LTR)**: آدرس‌های اینترنتی (URLs)، مسیرهای فایل‌ها و نام‌های دانلود به هیچ وجه دستکاری یا معکوس نمی‌شوند و کاملاً برای کپی و پخش امن باقی می‌مانند.
  - **محاسبه دقیق عرض کاراکترها**: عرض سلول‌ها با `rich.cells.cell_len` محاسبه می‌شود تا حروف فارسی و نیم‌فاصله‌ها (`‌`) خطوط و حاشیه‌های جدول را نامنظم نکنند.
  - **ایمنی در برابر تگ‌های استایل**: عناوین دریافت‌شده از سایت با `escape()` پردازش می‌شوند تا کروشه‌ها (مثل `[1080p]`) باعث خطای رندر نشوند.
- **سازگاری با ابعاد ترمینال**:
  - مدیریت خودکار و شکستن خطوط برای ترمینال‌های استاندارد 80x24.
  - تغییر خودکار به حالت کارتی فشرده در پنجره‌های کوچک‌تر از ۶۵ ستون.
- **پایداری پایپ‌لاین‌ها و خروجی‌های ماشین‌خوان**:
  - سازگاری کامل با فلگ `--no-color` و متغیر محیطی `NO_COLOR`.
  - عدم نفوذ استایل‌ها و رنگ‌های Rich به جریان‌های داده‌ای ماشین‌خوان (`--json` و `--plain`).

## 🛡️ امنیت دانلودر و دسترسی‌ها

- **حذف کامل نیاز به دسترسی ریشه (`sudo`)**:
  - دانلودها کاملاً تحت کاربر جاری و بدون افزایش دسترسی اجرا می‌شوند.
  - برنامه تحت هیچ شرایطی `sudo` یا دستورات مدیر بسته‌ها را اجرا نمی‌کند و هرگز درخواست رمز عبور سیستمی نخواهد کرد.
  - دانلود خودکار فایل‌های اجرایی نامعتبر از گیت‌هاب کاملاً حذف شده است.
- **شناسایی ابزارها منحصراً از مسیر `$PATH`**:
  - ابزارهای دانلود (`aria2c` و `curl`) و پلیرها صرفاً از طریق متغیر محیطی `$PATH` سیستم جست‌وجو می‌شوند تا از اجرای فایل‌های نامطمئن کنار برنامه جلوگیری شود.
  - در صورت عدم نصب `aria2c`، دستورات شفاف برای نصب دستی به کاربر نمایش داده می‌شود (`sudo apt install aria2`، `brew install aria2`، `winget install aria2`) و بلافاصله گزینه‌ی استفاده از `curl` یا کپی لینک‌ها فراهم می‌گردد.
- **اعتبارسنجی پیش‌دستانه‌ی دسترسی نوشتن و جلوگیری از نفوذ در مسیر (Path Traversal)**:
  - قبل از اجرای دانلود، مجوز نوشتن در دایرکتوری مقصد با `os.access(W_OK)` سنجیده می‌شود تا در صورت فقط-خواندنی بودن، خطای خوانا همراه با کد خروج `1` ثبت شود.
  - نام فایل‌ها پالایش شده (پاکسازی `..`، بایت‌های نال، کاراکترهای کنترلی و خط تیره‌های ابتدایی) و حضور فایل در داخل دایرکتوری مقصد تضمین می‌گردد.
- **فازبندی اتمیک و پاکسازی دانلودهای ناتمام**:
  - دانلودهای `curl` ابتدا به فایل موقت `.part` نوشته می‌شوند و تنها پس از اتمام موفق با `os.replace()` جایگزین می‌شوند.
  - با لغو دانلود (`Ctrl+C`) یا بروز خطا، فایل‌های ناقص `.part` پاک شده و برنامه با کد خروج استاندارد `130` خاتمه می‌یابد.
